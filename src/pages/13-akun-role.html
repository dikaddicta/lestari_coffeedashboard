Peran

Peran & Aturan Moderasi

Brewer

Input stok, brew log, dan QA sebagai data menunggu review. Tidak bisa menyetujui data sendiri.

QA

Bisa meninjau dan menyetujui/menolak brew log serta nilai QA di workspace.

Admin

Bisa menyetujui/menolak, mengedit, menghapus data bermasalah, dan mengelola workspace.

Moderasi

Panel Admin — Menunggu Tinjau / Disetujui / Ditolak

Setujui/Tolak tersedia untuk QA dan Admin. Hapus data hanya tersedia untuk Admin Workspace dan akan benar-benar menghapus row dari Supabase jika policy database sudah sesuai.
