Input Seduhan Manual

Menu ini untuk guest atau brewer yang ingin mencatat seduhan dengan rumus sendiri dan biji kopi sendiri. Data akan masuk ke Hasil Seduhan Publik hanya jika Final QA minimal 6.5.

Mode edit hasil seduhanForm edit memakai kolom yang sama seperti Input Seduhan. Tombol edit hanya muncul untuk akun yang menginput data tersebut.
1. Data SeduhanTanpa stok. Isi biji kopi dan resep manual yang kamu gunakan.
Multi-varietas Isi 2–3 varietas jika tertera di kemasan. Untuk label “Mix Varietas”, pilih Mix Varietas di Varietas 1 dan biarkan Varietas 2/3 opsional.
Detail PourIsi volume Pour 1 sampai Pour 4 sesuai resep manual.
2. Evaluasi SeduhanNilai sensorik menentukan apakah tombol simpan aktif. Minimal QA 6.5.
Final QA: 8.50 QA PASS
Parameter sudah konsisten Validasi dosis, rasio, total air, suhu, waktu, dan detail pour akan diperbarui otomatis.

Tombol simpan aktif karena Final QA memenuhi batas publik 6.5.
