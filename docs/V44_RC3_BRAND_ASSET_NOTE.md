# Catatan Aset Brand RC3

Sumber logo adalah file `lestari.png` yang dikirim pengguna. Bentuk bunga, jumlah kelopak, warna kelopak, dan pusat kuning tidak direka ulang.

Adaptasi yang dilakukan hanya:

1. resize untuk kebutuhan web;
2. penyimpanan master transparan;
3. penempatan gambar asli di atas bidang espresso untuk favicon kecil agar kelopak putih tetap terlihat;
4. penambahan padding dan ukuran canvas sesuai kebutuhan icon.

Aset hasil generative image sebelumnya tidak digunakan di dashboard.
